# Naga Jaswanth Bobba — UI/UX Designer Portfolio (React + Vite)

A modern, high-end, responsive portfolio web application built with **React**, **Vite**, and **Lucide Icons** specifically for UI/UX & Product Designer **Naga Jaswanth Bobba**, featuring the flagship case study **Smart Health Services — Healthcare Appointment Booking**.

---

## 🌟 Key Features

1. **Modern React Component Architecture**:
   - `Navbar`: Smooth section navigation, active link tracking on scroll, theme switcher, and review modal toggle.
   - `Hero`: High-resolution portrait of Naga Jaswanth Bobba with glowing perimeter, status badge, and floating micro-badges (*Figma Systems*, *User Journey & IA*).
   - `FeaturedCaseStudy`: Deep-dive into **Smart Health Services** with direct [Figma File](https://www.figma.com/design/4VwnEbzGMk1fjFOn6BfOTZ/Smart-Health-Services-%E2%80%94-Desktop-UI-UX?node-id=0-1&t=8KGBdmIA34YU60Xh-1) link and an **Interactive High-Fidelity Desktop Mockup Viewer** with switchable tabs:
     - 01. Service Discovery
     - 02. Doctor Directory
     - 03. Doctor Profile & Credentials
     - 04. Slot Scheduling & Calendar
     - 05. Patient Information & Confirmed Booking Card
   - `DesignProcess`: 4-step UX lifecycle breakdown (*Discover & Research*, *Information Architecture*, *UI & Design Systems*, *Prototyping & Testing*).
   - `About`: Designer mindset and 4 core philosophy pillars.
   - `Skills`: Categorized badges for UX Research, Visual Systems, and Tools.
   - `Contact`: Interactive inquiry form with project pills, timeline selector, message validation, and toast feedback.
   - `ReviewModal`: Live browser assistant to review and edit portfolio fields (Name, Title, Email, Tagline, Bio, Case Study text) with instant preview and `localStorage` persistence.

2. **Theming & Aesthetics**:
   - Default dark theme with glassmorphic cards and ambient lighting.
   - Instant Dark / Light theme toggle.

## 🚀 How to Run Locally

### 1. Start the React Development Server
In your terminal, navigate to the project directory and run:

```bash
npm run dev
```

> **Note for Windows PowerShell users:** If script execution is restricted on your machine, run:
> ```cmd
> cmd /c "npm run dev"
> ```

Then open your browser at:
👉 **[http://localhost:3000](http://localhost:3000)**

---

### 2. Build for Production
To create an optimized production build:

```bash
npm run build
```

The compiled files will be output to the `dist/` directory, ready to deploy to Vercel, Netlify, or GitHub Pages.

### 3. Preview Production Build
```bash
npm run preview
```
